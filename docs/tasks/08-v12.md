## T-V12-02 默认空间迁移与服务端 Schema

| 字段 | 值 |
| --- | --- |
| 里程碑 | M8 / P0 |
| 前置 | T-V12-01 |
| 需求 | REQ-SPACE-003、REQ-SPACE-005 |
| 预估 | 1 天 |

**目标**：通过 V004 在真实 SQLite 上建立空间表、空间归属、复合键、管理 ID 与空间同步状态，并完整迁移 v1.1 数据。

**必读**：`docs/api.md` §14、`docs/服务端技术架构.md` §6、ADR-0011。

**涉及路径**：`ClipboxServer/src/main/resources/migrations/V004__multi_space.sql`、服务端 `db/`、`src/test/.../db/`。

**实现要点**

- 迁移为旧数据创建 `legacy` 空间；保留设备 ID、token hash、剪贴记录、分享访问 token hash、配对码及 `server_seq/sync_floor`。
- 新 Schema：`devices.space_id/installation_id`、`clips.space_id` 与 `(space_id,id)` / `(space_id,server_seq)` 约束、`shares.space_id/share_id`、`device_pairing_codes.space_id`、`space_sync_state`。
- 旧表重建必须在一个迁移事务内完成；失败不得记录已应用版本。
- 分享管理 ID 使用 16 字节独立随机值的小写十六进制；不得从访问 token 或其哈希派生。

**验收**

```bash
cd ClipboxServer
./gradlew test --tests '*Migration*'
```

覆盖空库、v1.1 有数据库、再次启动不重复迁移、迁移失败原子回滚；使用临时 SQLite，不读取或修改正式 `data/`。

**DoD**：数据库检查证明历史值完整、所有行属于 `legacy`、空间序号保持原值；一卡一提交。

## T-V12-04 空间创建、配对与安装标识服务端流程

| 字段 | 值 |
| --- | --- |
| 里程碑 | M8 / P0 |
| 前置 | T-V12-03 |
| 需求 | REQ-SPACE-001、REQ-SPACE-005、AC-29、AC-30 |
| 预估 | 1 天 |

**目标**：实现显式创建空间、按码加入空间及同空间重复配对令牌轮换。

**涉及路径**：服务端 `api/`、`routes/PairingRoutes.kt`、`service/`、`db/`、配对集成测试。

**实现要点**

- `POST /spaces` 每 IP 3 次/分钟限流；事务内创建空间与首台设备。
- 新配对码归属已认证 issuer 的空间；旧匿名 issuer 只指向 `legacy`。
- `installationId` 校验 1–128 个允许字符；旧客户端缺省时服务端生成随机值。
- 同空间同标识在有效码配对成功后复用设备 ID、更新名称与 token hash、关闭旧 WS；跨空间同标识可独立存在。
- `/bootstrap` 仅当无任何空间时为旧客户端创建 `legacy`；成功/冲突语义不变。

**验收**：`cd ClipboxServer && ./gradlew test`；覆盖限流、原子创建、错空间码、旧客户端字段缺省、重复配对与旧 token/WS 失效。

## T-V12-05 客户端身份提供器与创建/加入流程

| 字段 | 值 |
| --- | --- |
| 里程碑 | M8 / P0 |
| 前置 | T-V12-04 |
| 需求 | REQ-SPACE-001、REQ-SPACE-004、REQ-SPACE-005 |
| 预估 | 1–2 天 |

**目标**：三端提供稳定安装标识，首次配对让用户明确选择创建空间或输入配对码加入。

**涉及路径**：`ClipboxClient/shared/` 配对 DTO/仓储；`composeApp/src/{commonMain,androidMain,iosMain,desktopMain}/` 身份提供器、配对 UI 与三语资源。

**实现要点**

- Android `ANDROID_ID`、iOS `identifierForVendor`、Desktop 在应用数据目录持久化随机 UUID；桌面 ID 不进入用户同步设置日志。
- 两种配对动作都提交安装标识；新 UI 不把留空码当作 bootstrap；配对后仍按原设备令牌认证。
- 同空间重复安装标识返回复用的 `deviceId`；客户端成功后替换本地 token 并重建会话。
- 切换空间前走现有解除配对确认并清空本地凭据、Room、Outbox 与游标；服务端旧空间数据不受影响。
- 不新增应用权限或依赖；用户文案进入三语 Compose Resources。

**验收**：共享层测试与 `./gradlew :composeApp:assembleDebug`；在 Android、iOS 模拟器、Desktop 手工检查身份来源与配对切换。记录卸载重装表现，不以安装标识恢复 token。

## T-V12-06 空间内设备与分享管理 API

| 字段 | 值 |
| --- | --- |
| 里程碑 | M8 / P1 |
| 前置 | T-V12-03、T-V12-04 |
| 需求 | REQ-MGMT-001…002、AC-31…33 |
| 预估 | 1 天 |

**目标**：提供仅限当前空间的设备列表/撤销、有效分享列表/撤销。

**涉及路径**：服务端 `routes/`、`service/`、`db/`、连接注册表与集成测试。

**实现要点**

- 设备列表返回名称、创建时间、最近活动、当前设备标记，不返回安装标识或 token。
- 撤销目标设备后立即拒绝 REST token 并关闭其 WS；末台设备撤销事务内清除该空间全部在线行与同步状态。
- 分享列表仅含未过期且仍可访问的记录（非一次性分享到期前有效，一次性分享消费后移出列表）；只返回 120 Unicode 码点预览及管理字段，不返回 token、token hash 或 URL。
- 两种跨空间管理 ID 均返回 404；删除分享使原 URL 返回 404；备份策略不变。

**验收**：`cd ClipboxServer && ./gradlew test`；覆盖当前设备撤销、末台删除、跨空间 404、分享消费过滤与主动撤销。

## T-V12-08 三项离线工具算法

| 字段 | 值 |
| --- | --- |
| 里程碑 | M8 / P2 |
| 前置 | T-V12-01 |
| 需求 | REQ-TOOL-010…012、AC-34 |
| 预估 | 1 天 |

**目标**：在共享层提供 JWT 解码、SHA-256、UUID/ULID 生成的纯函数/生成器。

**涉及路径**：`ClipboxClient/shared/src/commonMain/kotlin/.../toolbox/` 及对应 commonTest。

**实现要点**

- JWT 只分段解码、Base64URL 解码并解析头部与载荷 JSON；不校验签名、不校验有效期/issuer/audience。
- SHA-256 使用已有锁定运行时能力，不新增依赖；输入按 UTF-8 字节计算并输出小写 hex。
- UUID v4 使用安全随机源；ULID 遵守当前 Crockford 格式约束。
- 纯算法不依赖网络、Room、日志或剪贴历史。

**验收**：先按仓库测试协议完成测试环境检查；执行 `cd ClipboxClient && ./gradlew :shared:allTests`，覆盖非法 JWT、SHA-256 向量、UUID/ULID 格式。
