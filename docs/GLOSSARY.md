# Clipbox 领域词汇

Clipbox 是离线优先的跨设备文本中转与本地工具箱。本表固定产品与同步语义的规范用词，所有设计文档以此为准。

## 产品与数据

**剪贴记录（Clip）**:
设备发送的一条文本，是追加型数据，可同步到其他设备。
_Avoid_: 消息、文本、剪贴板内容、记录

**历史记录（Clip History）**:
剪贴记录按时间排列的可见集合。
_Avoid_: 列表、收件箱、剪贴板历史

**收藏片段（Snippet）**:
带标题、标签、可编辑、长期保存的文本，独立于历史记录。
_Avoid_: 收藏、片段、书签

**分享页（Share）**:
由剪贴记录生成的只读网页，有有效期，可设置为阅后即焚。
_Avoid_: 短链、外链

**分享链接（Share URL）**:
指向分享页的完整 URL，用于在任意浏览器中打开分享。
_Avoid_: 短链、外链

**工具箱（Toolbox）**:
纯本地、无网络依赖的文本处理工具集合。
_Avoid_: 工具集、插件、扩展

## 设备与身份

**用户空间（User Space）**:
同一服务端上一组相互配对的设备及其剪贴记录、分享与同步状态。一个用户可在服务端拥有多个互相隔离的用户空间，客户端一次只关联一个空间。
_Avoid_: 账号、租户、工作区

**设备（Device）**:
完成配对、持有独立设备令牌的客户端实例。
_Avoid_: 终端、客户端、节点

**配对（Pairing）**:
使用某空间成员签发的一次性配对码，将新设备登记到该成员所属空间的流程。
_Avoid_: 登录、绑定、注册

**配对码（Pairing Code）**:
空间成员设备按需生成并绑定其所在空间的 6 位数字一次性短码，用于让另一台设备加入同一空间；服务端只保存哈希。未认证匿名码仅为旧客户端兼容并限定默认旧空间。
_Avoid_: 邀请码、验证码、登录码、管理码

**空库初始化（Bootstrap）**:
旧客户端在没有任何空间的全新服务器上创建默认旧空间与首台设备的一次性操作；仅空库可用，已有空间返回 409。v1.2 客户端使用显式空间创建接口。
_Avoid_: 注册、首次登录、管理员初始化

**设备令牌（Device Token）**:
配对成功后颁发给设备的随机认证凭证。服务端只保存其 SHA-256 哈希；设备 ID 与安装标识都不能代替令牌认证。
_Avoid_: Token、密钥、密码

**安装标识（Installation Identifier）**:
平台提供或本地生成的稳定设备识别元数据，用于同一空间内识别应用安装，不用于认证或恢复设备令牌；系统条件变化后可能重置。
_Avoid_: 设备令牌、硬件序列号

**分享管理 ID（Share Management ID）**:
服务端为分享记录生成的独立随机标识，只用于已认证空间内查询和撤销；不等同于分享访问令牌。
_Avoid_: 分享令牌、分享 URL

## 同步与一致性

**服务端变更序号（Server Seq）**:
服务端在每个用户空间内为剪贴记录变更分配的单调递增整数，用于增量同步与事件排序。
_Avoid_: 版本号、时间戳

**同步游标（Sync Cursor）**:
客户端已拉取变更的位置标记，用于增量同步。
_Avoid_: 位点、offset、书签

**同步下界（Sync Floor）**:
服务端已清理墓碑的最大序号，早于该位置的增量游标必须全量重同步；全量分页以 `full=true` 显式豁免此判定，但仍受服务端最大序号约束。
_Avoid_: 清理线、水位

**全量同步（Full Sync）**:
从 `since=0` 起逐页拉取全部活跃记录与保留墓碑的过程，首次配对与强制重同步使用；每一页携带 `full=true`，直到 `hasMore=false`。
_Avoid_: 首次同步、初始化同步

**墓碑（Tombstone）**:
软删除后保留的记录占位，携带标识、序号与删除标记，用于离线同步。
_Avoid_: 删除记录、垃圾数据

**强制重同步（Resync）**:
客户端游标落后于服务端可保证范围时，保留待发队列并从 `since=0` 起以 `full=true` 全量重建本地已同步数据的过程。
_Avoid_: 重建、重新拉取

**待发队列（Outbox）**:
客户端持久化的待同步写操作队列，联网后按序重放。
_Avoid_: 发件箱、重试队列、缓冲区

**置顶（Pin）**:
使剪贴记录免于自动清理并优先展示的用户操作。
_Avoid_: 收藏、星标、标记

**软删除（Soft Delete）**:
以删除标记代替物理删除，使删除能同步到离线设备。
_Avoid_: 假删除、逻辑删除

**最后写入胜出（LWW）**:
收藏片段发生多端冲突时，以更新时间较晚者为准的解决规则。
_Avoid_: 覆盖、后写优先

## 平台行为

**剪贴板回环（Clipboard Loop）**:
自动写入剪贴板与自动上传剪贴板相互触发形成的循环。
_Avoid_: 死循环、回传、回声

## 发布与分发

**发布产物（Release Artifact）**:
面向最终用户交付、按平台与 CPU 架构命名的可安装文件；构建中间物与调试包不算。
_Avoid_: 构建产物、二进制、安装文件

**模拟器构建（Simulator Build）**:
只用于模拟器验证、不能安装到真机的 iOS 构建。
_Avoid_: iOS 包、开发包

**代码签名（Code Signing）**:
用私钥对安装包签名，使平台能验证来源与完整性；与传输层加密无关。
_Avoid_: 公证、加密

**公证（Notarization）**:
Apple 对 macOS 软件做恶意软件扫描并签发票据的流程；与代码签名不同。
_Avoid_: 签名、上架

**应用镜像（App Image）**:
jpackage 产出的免安装应用目录，不是单文件 `.AppImage` 格式。
_Avoid_: AppImage、绿色版

**发布流水线（Release Pipeline）**:
由版本 tag 或手动触发、负责构建、发布产物并可将产物上线官网下载区的自动化流程，不等同于常驻 CI。
_Avoid_: CI、持续集成

**下载清单（Download Manifest）**:
由发布流水线从实际产物生成、描述当前版本的平台可用性与文件名、大小、SHA-256 及三语发布说明的 JSON 文件（schema v2）；官网页面与更新描述接口运行时读取，是页面与客户端校验数值的唯一来源。
_Avoid_: 版本清单、releases.json、latest.json

**发行服务器（Distribution Server）**:
官方维护、托管官网下载区与公开更新描述的服务器；客户端检查更新只访问它，与用户配对的服务器无关。
_Avoid_: 更新服务器、官方服务器、CDN

**配对服务器（Paired Server）**:
用户完成配对后承载其剪贴记录同步与分享的服务器；客户端更新检查不使用它的地址，也不携带设备令牌。
_Avoid_: 同步服务器、自建服务器

**更新检查（Update Check）**:
客户端读取发行服务器上的更新描述、比较版本并决定是否提示新版本的行为；只读，不下载、不安装。
_Avoid_: 升级、版本检测、自动更新

**更新描述（Update Descriptor）**:
发行服务器把下载清单投影成的公开只读响应，含版本、发布日期、三语发布说明与各平台可用性；下载 URL 由服务端拼接，不含磁盘路径。
_Avoid_: 版本接口、更新 API、latest.json

**发布说明（Release Notes）**:
随版本发布的纯文本变更摘要，按简中 / 繁中 / 英文存放；缺失时服务端回退简中，客户端按纯文本展示并保留换行。
_Avoid_: 更新日志、changelog、发行说明

**安装包校验（Installer Verification）**:
下载完成后按更新描述中的 SHA-256 校验安装包完整性；不匹配即删除文件并提示失败，不证明来源真实性。
_Avoid_: 签名校验、完整性检查、哈希比对

**部署账号（Deploy Account）**:
发布流水线用于上传下载产物的服务器受限账户；只能写下载目录，无 sudo、无端口转发。
_Avoid_: 部署用户、CI 账号
