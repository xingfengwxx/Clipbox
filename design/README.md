# Clipbox 三端高保真设计 · 交付说明

Clipbox v1.0.0 的完整设计交付：Android 手机端 24 个屏态、Desktop 2 个状态、只读分享页 4 个状态，同一套设计语言、同一套需求依据。依据文档为 `docs/功能需求文档.md` 与 `docs/客户端技术架构.md`（2026-11-13 冻结）。

## 打开方式

| 文件 | 说明 |
| --- | --- |
| `Clipbox 三端设计.html` | 主交付。双击用浏览器打开，无网络依赖、无构建步骤、无控制台报错。 |
| `分享页.html` | 独立只读分享页。纯 HTML + CSS，无脚本、无外部资源；顶部预览控制条用于切换四态，不属于分享页本体。 |

主文件顶部控制条可切换 **主题**（跟随系统 / 浅色 / 深色）与 **产品语言**（简 / 繁 / EN），选择写入 localStorage，重开保持。手机屏均为可交互状态机，不是截图。

### 字体与字号

- UI：系统无衬线栈（`-apple-system / PingFang SC / Noto Sans SC / Roboto`）；元数据（设备名、时间、UTF-8 字节数、同步状态）用等宽栈（`Menlo / Consolas / Courier New`），是全产品的签名细节。
- 手机正文 15–16px（不低于 14px），标签不低于 12px；桌面正文 13–14px；触控目标不小于 48dp。
- 间距 4 / 8 / 12 / 16 / 24 / 32；列表走发丝分隔线；弹层 6–10px 圆角；按钮 3px。

### 组件

顶栏、同步状态、发送器（含字节计数）、记录行、状态角标、底部导航、NavigationRail、底部操作面板、对话框、Snackbar、工具卡、结果面板、空态线稿、开关、分段控件、输入框、按钮。

## 交互说明

- **主题 / 语言**：顶部控制条全局切换，弹层与 Snackbar 一起跟随；重开保持。
- **手机屏**：底栏切历史 / 工具箱 / 设置；搜索实时过滤；置顶即点即改；记录行打开操作面板；分享两步（选有效期 → 生成链接）；删除有二次确认；发送新增记录并实时计算 UTF-8 字节。
- **Desktop**：NavigationRail 切换；发送进入列表；设置中开关自动发送需隐私确认。
- **分享页**：页面外切换正常 / 过期 / 已使用 / 无效四态预览；页面本身静态，无脚本依赖。

## 设计决策

1. **文本是主角**：全产品没有装饰性图片，靠真实剪贴内容（会议纪要、JSON、SSH 命令、中英混排）撑起版面；唯一的图形资产是自建字标与空态线稿。
2. **仪器感的克制**：暖白纸面 + 发丝分隔线 + 等宽读数 + 单一信号橙；强调色只给当前状态、主操作和需要注意的同步状态。
3. **元数据像一行日志**：设备 / 时间 / 字节数 / 同步状态统一等宽小字，让「文本中转」的专业感来自信息本身，而不是装饰。
4. **状态不新增页面**：空态、搜索、离线、超限、失败都在历史页原地解决，降低认知负担。
5. **危险操作两次确认**：删除记录与解除配对都明确提示后果，危险色只在确认按钮上出现。
6. **分享页足够安静**：只有正文、到期提示与页脚，无导航、无品牌墙、无脚本；一次性链接用 410 区分「已使用」与「已过期」。

## 已知假设

- **设备框**：手机端以 Pixel 形态 Android 框呈现；iOS 与 Android 共享 Compose Multiplatform UI，本次不单独出 iPhone 框。
- **桌面框**：以 macOS 窗口呈现，行为按文档覆盖 Windows / macOS / Linux。
- **示例域名**：分享链接统一使用 `https://clip.example.com`，仅作演示，不指向真实服务。
- **品牌资产**：产品无既有 logo / 色板 / VI，字标、图标与色板均为本次提案，详见 `brand-spec.md`。
- **分享页语言**：主文件中的分享页样本跟随全局语言；独立 `分享页.html` 固定简体中文，便于对照评审。
- **方向记录**：三方向门展示了 C1 仪器清单、C4 剪贴卡片架、C5 硬件面板三版，用户选定 C1，记录见 `direction-approved.md`。
